          How it works

          The same flow as AirDrop or LocalSend, in the browser.

          1. 1

            Open it on both devices

            Phone and PC each get their own 6-digit pairing code. Both just need an internet connection — on the same Wi-Fi, transfers run at full local speed.

          2. 2

            Trade codes once

            Type the PC's code into the phone (or the other way round). The devices find each other and a bubble appears on both screens.

          3. 3

            Tap, send, done

            Pick files, tap the bubble, hit Send. The file streams directly between the two devices over an encrypted WebRTC connection — no account, no cloud copy.

          One honest note: browsers can't scan your Wi-Fi network or use Bluetooth for file transfer the way native apps can, so discovery here works by pairing code instead of auto-scanning. A native version (like LocalSend) could auto-find devices on the same Wi-Fi — this page is the web version of the same idea, ready to put on GitHub Pages.
