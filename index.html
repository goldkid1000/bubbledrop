Install BubbleDrop on your phone

Put BubbleDrop on your home screen and it opens full-screen like a real app — no browser bars, no app store, nothing to download from a store. Pairing and sending work exactly the same.

iPhone — Safari Your phone

  1. Open this BubbleDrop page in Safari (installing only works from Safari on iPhone).
  2. Tap the Share button — the square with an arrow pointing up, at the bottom of the screen.
  3. Scroll down in the share sheet and tap Add to Home Screen.
  4. Tap Add in the top-right corner. BubbleDrop lands on your home screen.

Android — Chrome Your phone

  1. Open this BubbleDrop page in Chrome.
  2. Tap the ⋮ menu in the top-right corner.
  3. Tap Install app (on some phones it says Add to Home screen).
  4. Tap Install to confirm. BubbleDrop lands on your home screen and in your app drawer.

Viewing this inside another app (like the Muse app)? Its built-in browser can't install apps — open the BubbleDrop page in Safari or Chrome on your phone first, then follow the steps above. On a computer, Chrome and Edge show an install icon in the address bar, and the Install button above works there too.

          How it works

          The same flow as AirDrop or LocalSend, in the browser.

          1. 1

            Open it on both devices

            Phone and PC each get their own 6-digit pairing code. Both just need an internet connection — on the same Wi-Fi, transfers run at full local speed.

          2. 2

            Trade codes once

            Type the PC's code into the phone (or the other way round). The devices find each other and a bubble appears on both screens.

          3. 3

            Tap, send, done

            Pick files, tap the bubble, hit Send. The file streams directly between the two devices over an encrypted WebRTC connection — no account, no cloud copy.

          One honest note: browsers can't scan your Wi-Fi network or use Bluetooth for file transfer the way native apps can, so discovery here works by pairing code instead of auto-scanning. A native version (like LocalSend) could auto-find devices on the same Wi-Fi — this page is the web version of the same idea, ready to put on GitHub Pages.

          Beam the link to your other device

          Adds a link file to your Send queue — connect a device on the Send Files tab and hit Send, and the video link lands over there.

          How installing works: a web page alone can't pull YouTube's video stream directly, so when you tap Install, BubbleDrop sends just the video link to Cobalt — a free, open-source download processor — which prepares the MP4 or MP3 and hands the file straight back to your browser to save. BubbleDrop itself has no server and stores nothing; nothing but the link you pasted is sent. If the processor is busy, wait a few seconds and tap Install again.

            How it works

            Three steps, same as the big downloader sites — minus the sign-up wall.

            1. 1

              Paste the link

              Copy any YouTube link — a watch page, a Short, a youtu.be short link — and paste it above.

            2. 2

              Preview & pick

              BubbleDrop loads the title, channel, and thumbnail straight from YouTube so you can check it's the right video before downloading anything.

            3. 3

              Install, save, or beam it

              Tap Install Video for the MP4 or Install Audio for the MP3 — the file saves to this device's Downloads, ready offline. You can also save the thumbnail or details, or beam the link to your phone or PC.
